# Used Car Price Prediction using Machine Learning
## Project Overview

This project builds a Machine Learning model to estimate the price of a used car based on important vehicle attributes such as car name, manufacturer, manufacturing year, kilometers driven, and fuel type.

The project demonstrates an end-to-end Machine Learning workflow, beginning with raw data cleaning and exploratory analysis, followed by feature preprocessing, regression model training, evaluation, and prediction of used car prices.

The main objective is to understand how different vehicle characteristics influence resale value and to develop a regression model capable of estimating the expected price of a used car.

## Features Used

The model uses the following input features:

* Name
* Company
* Year
* Kms Driven
* Fuel Type

**Target Variable:**

* Price

## Data Cleaning and Preprocessing

The original dataset contained several inconsistent and missing values. The following preprocessing steps were performed:

* Cleaned inconsistent car names.
* Removed unnecessary words and descriptions from car names.
* Handled invalid company values.
* Removed non-numeric entries from the `year` column.
* Converted the `year` column to integer format.
* Removed rows containing `"Ask For Price"`.
* Removed commas from price values and converted them to numeric format.
* Cleaned the `kms_driven` column by extracting numerical values.
* Removed invalid entries from the `kms_driven` column.
* Handled missing values.
* Removed rows with missing `fuel_type` values.
* Reset the DataFrame index after cleaning.

The cleaned dataset was then used for exploratory analysis and model training.

## Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to better understand the dataset and identify relationships between vehicle features and price.

The analysis includes visualizations for:

* Company vs Price
* Year vs Price
* Kilometers Driven vs Price
* Fuel Type vs Price

These visualizations help reveal patterns and trends that influence the resale value of used cars.

## Feature Encoding

Since some input features are categorical, they were converted into numerical representations using **One-Hot Encoding**.

The categorical features encoded were:

```text
Name
Company
Fuel Type
```

Scikit-learn's `ColumnTransformer` was used to apply One-Hot Encoding to categorical columns while preserving the numerical features.

## Machine Learning Model

A regression-based Machine Learning model was trained to predict used car prices.

The workflow included:

* Selecting the relevant features.
* Splitting the dataset into training and testing sets.
* Encoding categorical variables.
* Training the regression model.
* Evaluating the model on unseen test data.
* Using the trained model to estimate the price of new cars.
